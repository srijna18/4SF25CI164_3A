# Zomato Data Analysis using Python

## Project Overview
This project analyzes Zomato restaurant data using Python to understand restaurant ratings, online ordering, restaurant types, and customer votes.

## Dataset Information
- Dataset: Zomato Restaurant Dataset
- Records: 148
- Columns: 7

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Tasks Performed
1. Loaded the dataset using Pandas.
2. Explored the dataset and its data types.
3. Cleaned and transformed the data.
4. Converted restaurant ratings into numeric values.
5. Checked and handled missing values using mean imputation wherever applicable.
6. Created a new column called `Rating_Category`.
7. Generated meaningful insights.
8. Created visualizations using Matplotlib.

## Visualizations
- Distribution of Restaurant Ratings
- Online Order Availability
- Top Restaurant Types
- Restaurant Ratings vs Votes

## Conclusion
This project demonstrates data cleaning, transformation, analysis, and visualization using Python. It helps identify useful patterns and insights from Zomato restaurant data.
